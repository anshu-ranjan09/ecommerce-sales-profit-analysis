# E-Commerce Sales & Profit Analysis

An end-to-end Data Analytics project analyzing e-commerce sales, profit, customers, regions, categories, and payment methods using SQL, Excel, and Power BI.

## 📌 Project Overview

This project focuses on analyzing an e-commerce dataset to identify sales performance, profitability, customer trends, regional performance, and payment-mode patterns.

The project demonstrates the complete data analytics workflow:

- Data preparation using Excel
- Data analysis using SQL
- KPI calculation
- Interactive dashboard development using Power BI
- Business insights generation

## 🛠️ Tools & Technologies

- Excel
- MySQL
- Power BI
- SQL
- DAX

## 📊 Dataset

The dataset contains 1,000 e-commerce orders with information including:

- Order ID
- Order Date
- Customer ID
- Customer Name
- Segment
- Region
- City
- Category
- Sub-Category
- Quantity
- Unit Price
- Discount
- Sales
- Profit
- Payment Mode

## 📊 Power BI Dashboard

The interactive dashboard includes:

- Sales by Region

- Sales by Payment Mode

- Region, Category, Segment and Payment Mode slicers

## 🔍 SQL Analysis

SQL was used to perform:

- Overall sales and profit analysis
- Category-wise performance analysis
- Region-wise performance analysis
- Top 10 customer analysis
- Monthly sales trend analysis
- Payment mode analysis
- Customer segment analysis
- Profit margin calculation

## 💡 Key Analysis Areas

The project helps answer questions such as:

- Which category generates the highest sales?
- Which region performs best in terms of sales?
- Who are the top customers?
- How do sales change month by month?
- Which payment modes are commonly used?
- Which customer segments contribute most to sales and profit?
- What is the overall profit margin?
